# LIMEN RESEARCH 로고

LIMEN / 짧고 굵은 막대 + 긴 가는 선 / RESEARCH. 막대는 문지방, 선은 바닥입니다.
보고서 표지에 쓰던 '가는 선 위의 짧고 굵은 막대'를 로고로 올린 것이라, 표지와 사이트와 로고가 같은 장치를 씁니다.
강조색은 막대 하나에만 씁니다 (사이트는 청록, PDF 표지는 빨강).

글자는 IBM Plex Sans(SIL 오픈 폰트 라이선스)를 윤곽선으로 딴 것이라 폰트가 없는 곳에서도 그대로 보입니다.
**다시 그리거나 늘리지 말고 이 폴더의 파일을 그대로 씁니다.**

사이트 파비콘(`static/favicon.svg`, `favicon-32.png`), 아이폰 홈 화면 아이콘(`apple-touch-icon.png`), 링크 미리보기 이미지(`og.png`)는 한 단계 위 `static/` 에 있습니다.

## 보고서 표지에 넣는 법

1. 표지 맨 아래의 **빨간 막대 + 가는 선**과 **'LIMEN RESEARCH' 글자**를 지웁니다. 로고가 같은 장치를 이미 품고 있어서 둘 다 두면 두 번 나옵니다.
2. 그 자리에 `logo-cover.png`(또는 `.svg`)를 넣습니다.
   - 크기: 폭 **22~26mm** (A4 기준).
   - 위치: 왼쪽 끝을 제목 글과 같은 여백에 맞추고, RESEARCH 아랫선을 오른쪽 '퍼플' 글자의 아랫선에 맞춥니다.
3. 선을 판면 끝까지 늘리지 않습니다.
4. 제목 아래의 빨간 막대 + 가는 선은 그대로 둡니다.

## 크기와 여백

- 로고 둘레는 최소 **LIMEN 글자 높이의 절반**만큼 비웁니다. 표지에서는 글자 높이만큼 비우길 권합니다.
- 최소 크기: 인쇄 폭 **16mm**, 화면 높이 **28px**. 그보다 작은 곳에는 아이콘만 씁니다.
